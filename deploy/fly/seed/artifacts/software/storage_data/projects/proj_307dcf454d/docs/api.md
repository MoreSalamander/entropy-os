# DollarWise — API

## lesson_service

- `GET /lesson_contents` — List LessonContent records _(entity: LessonContent)_
- `POST /lesson_contents` — Create a LessonContent _(entity: LessonContent)_
- `GET /lesson_contents/{item_id}` — Fetch one LessonContent _(entity: LessonContent)_
- `DELETE /lesson_contents/{item_id}` — Delete a LessonContent _(entity: LessonContent)_
- `GET /quizs` — List Quiz records _(entity: Quiz)_
- `POST /quizs` — Create a Quiz _(entity: Quiz)_
- `GET /quizs/{item_id}` — Fetch one Quiz _(entity: Quiz)_
- `DELETE /quizs/{item_id}` — Delete a Quiz _(entity: Quiz)_
