Why the two kinds of verdict

A hard verdict is a recorded fact — a linter's exit code, a test suite's count, a build that either succeeded or did not.

A soft verdict is a judge model's opinion. It can inform you and it can never grant acceptance.

A run is accepted only if at least one hard gate passed and every hard gate passed. An engine that checked nothing has proven nothing, so silence is never success.
