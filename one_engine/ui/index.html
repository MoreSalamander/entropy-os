What this is

Four autonomous AI engines converge into one engine — and that engine can be composed again.

Not four applications wired together. Independent engines join into a unified system through a single contract, and the unified system exposes that same contract — so it can become a capability inside something larger. Composition is recursive by construction, not by special case.

research + software + university + web ↓ UNIFIED INTELLIGENCE ↓ CAPABILITY ↓ HIGHER SYSTEM ↓ BEYOND

Every arrow is the same move: a system that speaks the contract becomes a capability another system consumes by URL — without knowing what is inside it.

The four stay four

Each keeps its own codebase, agents, external search, Context Graph, Knowledge Graph, and DataHub platform. Not one line of those four repositories was modified — each adapter runs inside its engine's own environment and calls its existing front door.

The keystone: one contract

Every engine — leaf or composite — serves the same nine routes: identity, capabilities, context, knowledge, state, health, events, execute, and event ingest.

Because a composite serves exactly what it consumes, one small client class is the whole composition mechanism at every level. If recursion needed a different mechanism one level up, the claim would be false.

Four layers, four owners

Parallelperception — the engines' own acquisition, reused, never duplicated
DataHubmemory — what the system knows: identity, relationships, provenance
Agentsreasoning — each engine's own specialists, untouched
Temporalexecution — what the system is doing: state, retries, signals, recovery

Temporal is never the knowledge graph; DataHub is never the workflow state. Enforced by packaging — an engine cannot import Temporal.

Reading this page

Objective is one request crossing every engine. Each stage's inputs are built from what earlier stages produced: research shapes the curriculum, the curriculum shapes the software request, the software's product name shapes the web brief.

What the system is doing is the semantic event log — past-tense facts. No event tells another engine what to do; that restraint is what keeps them autonomous while the system behaves as one.

Federation, not flattening: each engine keeps publishing to its own DataHub platform. A composed run adds only the cross-domain edges, so it renders as one graph spanning five platforms.

Honest degradation

Health reads ok only when the system can deliver what the architecture promises. Without DataHub there is no provenance; without Temporal there is no durability — both report degraded rather than pretending. A run still completes either way, and provenance records which orchestrator actually ran.
